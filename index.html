Introducción y definiciones

Para saber dónde una función alcanza sus valores más altos o más bajos en una zona, usamos derivadas. El criterio de la segunda derivada es un método rápido para decidir si un punto crítico es máximo o mínimo. Se usa en optimización: ganancias, áreas, costos.

Al terminar podrás:
  1. Hallar los puntos críticos de una función.
  2. Aplicar el criterio de la segunda derivada.
  3. Resolver un problema sencillo de optimización.
Conocimientos previos: reglas de derivación y resolver ecuaciones.

Punto crítico (raíz de la derivada)

Es un valor x = c del dominio donde f′(c) = 0 (o donde f′ no existe). Ahí la recta tangente es horizontal. Se encuentra resolviendo la ecuación f′(x) = 0.

Concavidad

Si f″(x) > 0 la gráfica abre hacia arriba (forma de copa ∪). Si f″(x) < 0 abre hacia abajo (forma de ∩).

Criterio de la segunda derivada

Sea f′(c) = 0 y f″ continua cerca de c:

Valor de f″(c)Conclusión
f″(c) > 0f tiene un mínimo en c
f″(c) < 0f tiene un máximo en c
f″(c) = 0El criterio no decide; usar otro método (criterio de la primera derivada)

Pasos del método

  1. Calcular f′(x) y f″(x).
  2. Resolver f′(x) = 0 para hallar los puntos críticos.
  3. Evaluar f″ en cada punto crítico y aplicar la tabla.
  4. Calcular f(c) para dar el punto completo (c, f(c)).

¿Por qué funciona? La idea intuitiva

La segunda derivada mide cómo cambia la pendiente. Si en un punto crítico la pendiente es cero y f″(c) > 0, la pendiente está aumentando: antes era negativa (la curva bajaba) y después será positiva (la curva sube). Eso forma un valle, es decir, un mínimo. Si f″(c) < 0 ocurre lo contrario: la curva sube y luego baja, formando una cima.

La línea roja punteada es la recta tangente horizontal en el punto crítico.

Relación con el criterio de la primera derivada

Ambos criterios llegan a la misma conclusión. El de la primera derivada mira el signo de f′ a ambos lados de c:

Signo de f′ antes de cSigno de f′ después de cConclusión
−+Mínimo
+−Máximo
+ o −mismo signoNo hay extremo

Cuando f″(c) = 0: tres posibilidades

FunciónEn x = 0Resultado
f(x) = x⁴f′(0) = 0, f″(0) = 0Mínimo
f(x) = −x⁴f′(0) = 0, f″(0) = 0Máximo
f(x) = x³f′(0) = 0, f″(0) = 0Ni máximo ni mínimo

Por eso, si f″(c) = 0, no se puede concluir nada con este criterio y hay que usar el signo de f′.

Máximos y mínimos en un intervalo cerrado

Si la función se estudia en un intervalo cerrado [a, b], además de los puntos críticos hay que comparar los valores de f en los extremos a y b. El mayor de todos esos valores es el máximo en el intervalo y el menor es el mínimo.

Errores comunes

  • Olvidar derivar dos veces o confundir f′ con f″.
  • Evaluar f″ en lugar de f para dar la altura del punto (la coordenada y).
  • Concluir «mínimo» solo porque f″(c) = 0. Ese caso no decide.
  • Dejar fuera puntos críticos al factorizar (por ejemplo, perder x = 0 en 4x(x² − 4)).
  • Aceptar soluciones fuera del dominio en problemas de aplicación.
Resumen: derivar dos veces → f′(x) = 0 → evaluar f″ en cada solución → ( + mínimo, − máximo, 0 no decide ) → calcular f(c).

Problemas resueltos

Problema 1

Clasifica los puntos críticos de f(x) = x³ − 6x² + 9x + 2.

1) f′(x) = 3x² − 12x + 9 y f″(x) = 6x − 12.
2) 3x² − 12x + 9 = 0 ⇒ 3(x − 1)(x − 3) = 0, entonces x = 1 y x = 3.
3) f″(1) = −6 < 0 ⇒ máximo. f″(3) = 6 > 0 ⇒ mínimo.
4) f(1) = 1 − 6 + 9 + 2 = 6; f(3) = 27 − 54 + 27 + 2 = 2.

✔ Comprobación: f′(0) = 9 > 0 (la curva sube), f′(2) = −3 < 0 (baja) y f′(4) = 9 > 0 (sube). La pendiente pasa de + a − en x = 1 (máximo) y de − a + en x = 3 (mínimo).

Respuesta: máximo en (1, 6) y mínimo en (3, 2).

Problema 2

Clasifica los puntos críticos de f(x) = x⁴ − 8x² + 3.

1) f′(x) = 4x³ − 16x y f″(x) = 12x² − 16.
2) 4x(x² − 4) = 0 ⇒ x = 0, x = 2, x = −2.
3) f″(0) = −16 < 0 ⇒ máximo. f″(±2) = 32 > 0 ⇒ mínimos.
4) f(0) = 3; f(±2) = 16 − 32 + 3 = −13.

✔ Comprobación: el signo de f′(x) = 4x(x² − 4) en cada tramo es: x = −3 → −; x = −1 → +; x = 1 → −; x = 3 → +. Cambia de − a + en x = −2 y x = 2 (mínimos) y de + a − en x = 0 (máximo).

Respuesta: máximo en (0, 3); mínimos en (−2, −13) y (2, −13).

Problema 3 (aplicación)

Un rectángulo tiene perímetro de 40 m. ¿Qué dimensiones dan el área máxima?

1) Si un lado es x, el otro es 20 − x. Área: A(x) = x(20 − x) = 20x − x².
2) A′(x) = 20 − 2x = 0 ⇒ x = 10.
3) A″(x) = −2 < 0 ⇒ máximo.
4) Comprobación: A(10) = 100; con x = 9, A = 99, y con x = 11, A = 99, menores.

Respuesta: un cuadrado de 10 m × 10 m, con área máxima de 100 m².

Problema 4

Clasifica los puntos críticos de f(x) = x³ − 3x² − 9x + 5.

1) f′(x) = 3x² − 6x − 9 y f″(x) = 6x − 6.
2) 3(x² − 2x − 3) = 3(x − 3)(x + 1) = 0, entonces x = 3 y x = −1.
3) f″(3) = 12 > 0 ⇒ mínimo. f″(−1) = −12 < 0 ⇒ máximo.
4) f(3) = 27 − 27 − 27 + 5 = −22; f(−1) = −1 − 3 + 9 + 5 = 10.

✔ Comprobación: f′(−2) = 15 > 0, f′(0) = −9 < 0 y f′(4) = 15 > 0. La pendiente pasa de + a − en x = −1 (máximo) y de − a + en x = 3 (mínimo).

Respuesta: máximo en (−1, 10) y mínimo en (3, −22).

Problema 5 (cuando el criterio no decide)

Analiza el punto crítico de f(x) = x³.

1) f′(x) = 3x² y f″(x) = 6x.
2) 3x² = 0 ⇒ x = 0.
3) f″(0) = 0: el criterio no decide.
4) Primera derivada: para x = −1, f′ = 3 > 0; para x = 1, f′ = 3 > 0. El signo no cambia.

Respuesta: en x = 0 no hay máximo ni mínimo; la función siempre crece.

Problema 6 (aplicación: volumen máximo)

De una hoja cuadrada de 12 cm de lado se cortan cuadrados de lado x en las esquinas y se doblan los lados para formar una caja sin tapa. ¿Qué x da el mayor volumen?

1) Base: (12 − 2x) por (12 − 2x); altura: x. V(x) = x(12 − 2x)² = 4x³ − 48x² + 144x, con 0 < x < 6.
2) V′(x) = 12x² − 96x + 144 = 12(x − 2)(x − 6) = 0, entonces x = 2 o x = 6. Se descarta x = 6 (fuera del dominio abierto, la caja sería plana).
3) V″(x) = 24x − 96; V″(2) = −48 < 0 ⇒ máximo.
4) V(2) = 2 · 8² = 128.

✔ Comprobación: V(1) = 1 · 10² = 100 cm³ y V(3) = 3 · 6² = 108 cm³, ambos menores que V(2) = 128 cm³.

Respuesta: cortar cuadrados de 2 cm; el volumen máximo es 128 cm³.

Problemas propuestos

Ordenados de menor a mayor dificultad. Clasifica los puntos críticos de cada función y da las coordenadas.

  1. f(x) = x² − 6x + 5
  2. f(x) = −2x² + 8x
  3. f(x) = x³ − 3x
  4. f(x) = 2x³ − 9x² + 12x
  5. f(x) = x⁴ − 4x³ (un punto crítico no se decide con f″; analízalo con la primera derivada)
  6. La ganancia de una empresa es G(x) = −x² + 60x − 500 (miles de quetzales, x unidades). ¿Cuántas unidades dan la ganancia máxima y cuál es?
  7. f(x) = x³ − 12x + 1
  8. f(x) = x⁴ − 2x²
  9. f(x) = x³ + 3x² − 24x
  10. f(x) = 3x⁵ − 5x³ (hay un punto donde f″ vale 0: analízalo con la primera derivada)
  11. Se quiere cercar un terreno rectangular junto a un río con 100 m de cerca. El lado del río no necesita cerca. ¿Qué dimensiones dan el área máxima y cuál es?
  12. Dos números positivos tienen producto 36. ¿Cuáles deben ser para que su suma sea mínima? (Pista: S(x) = x + 36/x)

  2. Máximo en (2, 8).
  3. Máximo en (−1, 2); mínimo en (1, −2).
  4. Máximo en (1, 5); mínimo en (2, 4).
  5. x = 0: f″(0) = 0, no decide (f′ no cambia de signo, no es extremo). x = 3: mínimo en (3, −27).
  6. x = 30 unidades; ganancia máxima G(30) = 400 (miles de quetzales).
  7. Máximo en (−2, 17); mínimo en (2, −15).
  8. Máximo en (0, 0); mínimos en (−1, −1) y (1, −1).
  9. Máximo en (−4, 80); mínimo en (2, −28).
  10. Mínimo en (1, −2); máximo en (−1, 2); en x = 0, f″ = 0 y f′ no cambia de signo (negativa a ambos lados), por lo que no hay extremo.
  11. Lados de 25 m (perpendiculares al río) y 50 m (paralelo al río); área máxima 1250 m².
